# 厦门工学院实验室安全培训 - 自动挂机脚本

## 📖 简介
这是一个用于厦门工学院实验室安全培训考试系统（`exam.xit.edu.cn`）的油猴（Tampermonkey）脚本。
主要用于解决挂机学习时，系统每 5 分钟弹出“是否继续阅读”导致挂机中断的问题。

> **⚠️ 重要声明**：经过严格测试，该系统后端采用**服务器真实时间校验**，任何通过前端修改时间戳、加速定时器、疯狂发送心跳包的“秒刷”尝试均无效，且可能导致账号被风控。
> 因此，本脚本放弃“秒刷”功能，主打**绝对安全、稳定防掉线**。

## ✨ 功能特性
- 🖱️ **自动点击确认**：自动接管浏览器原生 `confirm` 弹窗，以及网页自定义的“确定”按钮。
- 🛡️ **安全稳定**：不修改任何网页原本的请求频率，服务器端完全无感，绝对不会被判定为作弊。
- 📊 **可视化面板**：网页右下角悬浮窗实时显示脚本运行状态、拦截弹窗次数、最后检测时间。

## 🚀 安装与使用
1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 插件。
2. 点击上方 `xit-auto-study.user.js` 文件，点击 `Raw` 按钮，Tampermonkey 会自动弹出安装提示。
3. 或者直接新建脚本，将代码复制进去保存。
4. 打开学习页面，右下角出现绿色“稳定挂机保护中”面板即代表成功。

## 💡 挂机小贴士
1. 请将电脑电源设置中的“睡眠”改为**“从不”**。
2. 建议保持该网页在前台，或确保浏览器没有开启深度休眠模式。
3. 挂满时长后，记得手动去完成考试。
