## 📖 项目简介
这是一个专为厦门工学院实验室安全培训考试系统（`exam.xit.edu.cn`）编写的油猴（Tampermonkey）辅助脚本。

主要用于解决挂机学习时，系统每 5 分钟弹出“是否继续阅读”导致挂机中断的问题。同时，针对现代浏览器“后台标签页休眠”的机制，本脚本加入了 **Web Worker 与静音音频保活** 技术，让你可以放心将浏览器最小化去干别的事。

> ⚠️ **重要声明（必看）**：
> 经过严格测试，该系统后端采用**服务器真实时间校验**。任何通过前端修改时间戳、加速定时器、疯狂发送心跳包的“秒刷”尝试均无效，且极易导致账号被风控。
> 因此，本脚本**放弃秒刷功能**，主打**绝对安全、稳定防掉线**。

## ✨ 核心功能
- 🖱️ **全自动确认**：接管浏览器原生弹窗与网页自定义弹窗，自动点击“确定/继续阅读”。
- 🔒 **后台防休眠保活**：开启后，利用静音音频和独立线程欺骗浏览器，最小化也不影响网页计时。
- 📊 **可视化面板**：网页右下角悬浮窗实时显示运行状态、拦截次数、心跳时间。
- 🛡️ **安全透明**：不修改任何网页原本的请求频率，服务器端完全无感。

## 🚀 安装与使用
### 1. 安装脚本
1. 浏览器需提前安装 [Tampermonkey (油猴)](https://www.tampermonkey.net/) 插件。
2. 点击上方文件列表中的 `xit-auto-study.user.js`。
3. 在代码页面点击右上角的 **`Raw`** 按钮，油猴会自动弹出安装界面，点击“安装”即可。

### 2. 挂机操作指南
1. 打开你需要学习的培训页面。
2. 网页右下角会出现一个黑色控制面板，点击 **“🚀 开启后台防休眠”**。
3. 等待状态变为绿色的 **“🔒 深度保活中 (可最小化)”**。
4. **现在你可以安心把浏览器最小化了！**（建议将电脑系统的“睡眠”设置为“从不”）。

## ⚠️ 常见问题
- **为什么最小化后时间不涨？** 请确保你点击了面板上的“开启后台防休眠”按钮，并且听到/看到了静音播放的提示。
- **会被学校系统查出来吗？** 只要你开启的是 V9.1 纯净版，脚本仅代替你点击了弹窗，发包频率与正常挂机完全一致，属于安全的辅助工具。
